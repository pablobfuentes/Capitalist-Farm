# 8.2 — Dashboard debrief, progress graph, RE improvements, securities & loans

**Purpose:** Implementation plan for five player-facing features requested after the P2 / Phase 6 Godot port. Tracks **what exists**, **what to build**, and **acceptance criteria** per phase.

**Scope:** **Capital Farm** (`mode: arcade`) only. UI may differ from the HTML MVP; simulation numbers and consequences should match MVP rules.

**Related:**
- Architecture → [`8.0_godot_migration.md`](8.0_godot_migration.md)
- Mechanics parity checklist → [`8.1_capital_farm_mechanics_parity.md`](8.1_capital_farm_mechanics_parity.md)
- MVP oracle → `EconomyGame_MVP (6).html`

---

## Features in scope

1. **Turn advance debrief** — profit summary with before/after comparison (MVP turn debrief modal + card)
2. **Live progress graph** — NW / Cash / Debt on dashboard during play (not only game-over)
3. **Securities / stock market** — buy shares, hold, sell (audit + polish; backend largely exists)
4. **Real estate improvements** — farm RE mode for **Delivery Cold Storage** and **Equipment & Repair Shed**
5. **Bank loans from Opportunities** — accept line-of-credit offers (audit + polish; backend largely exists)

---

## Current state (baseline)

| Feature | Godot today | Gap vs MVP |
|--------|-------------|------------|
| **Turn profit summary** | One-line `DebriefLabel` from `last_advance_report` in `dashboard.gd` | No before/after modal, no profit delta narrative, no collapsible card |
| **Progress graph** | `run_report_graph.gd` — net worth only, **game-over screen only** | MVP shows NW + Cash + Debt on dashboard every turn (`drawGraph`) |
| **Securities** | `security_system.gd` + opp roll (~10%) + buy/sell UI + GUT tests | Largely done; UX polish (cost basis, P&L indicator) |
| **Delivery / repair shed RE** | Templates in `farm_content.json`; buy via Opportunities | No improve flow (`doImproveRealEstate` / `FARM_REAL_ESTATE_IMPROVEMENTS`) |
| **Loans from Opportunities** | `_make_financing_opportunity` + `LoanSystem.take_loan` + Accept button | Largely done; ~10% roll may feel rare |

**Net new work:** debrief system + modal UI, live multi-series graph, real estate improvement system + UI. **Audit/polish:** securities and loans.

---

## Suggested implementation order

```
Phase 1 (Turn debrief) → Phase 2 (Live graph) → Phase 3 (RE improvements)
                                                      ↓
                              Phase 4 (Securities audit) → Phase 5 (Loans audit)
```

1. **Turn debrief** — highest visibility; unblocks manual QA for profit verification
2. **Live graph** — reuses `turn_history` populated by debrief/advance pipeline
3. **RE improvements** — only substantial new mechanics in this list
4. **Securities + loans audit** — confirm existing code meets expectations; small UX fixes

## Manual smoke script (after all phases)

1. New Capital Farm run → advance once → **debrief modal** shows revenue, costs, profit, NW delta → Continue.
2. Dashboard **graph** shows NW/Cash/Debt line after 2+ turns.
3. When security opp appears → buy 10 shares → advance → price moves → sell → cash updates.
4. When loan opp appears → Accept → cash up, debt in graph → debt service in next debrief.
5. Acquire **Equipment & Repair Shed** or **Delivery Cold Storage** → **Improve** (e.g. Cold-Room Expansion) → val/rent up in portfolio.
6. Own downstream business without repair/delivery → chain-hint RE listing appears.
