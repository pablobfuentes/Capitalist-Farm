# 8.5 — Supply Chain Map Visualization

**Purpose:** Interactive Supply Chain View overlaid on the isometric farm map — curved dotted trade routes, ownership colors, direction animation, and path cycling for branches.

**Spec:** [`docs/SUpply_Chain_visualization.txt`](docs/SUpply_Chain_visualization.txt)

**Related:**
- Existing abstract diagram → `godot/ui/screens/supply_chain_diagram.gd` / `supply_chain_view.tscn` (keep; this feature is map-overlaid)
- Connection catalog → `godot/data/connections/supply_connection.gd` + `Content.connections`
- Active links / ownership math → `godot/core/systems/synergy_system.gd`
- Parcel ↔ business mapping → `godot/core/systems/parcel_ownership_system.gd`
- Map chrome → `godot/scenes/farm_map/iso_farm_map.*`

**Status values:** `[ ]` todo · `[~]` in progress · `[x]` done · `[-]` cut / deferred

## Decisions

| # | Question | Decision |
|---|----------|----------|
| Q1 | Blue “owned” connection | **Player owns both endpoint businesses** (supplier + customer). |
| Q2 | Clicks while mode on | **1st click** → select / show chain · **2nd click** (same building) → open parcel panel. |
| Q3 | Visible scope | **Focused district only** (not overview-wide). |
| Q4 | NPC / opportunity parcels | **Include** as nodes; their links render **white** until both ends are player-owned. |
| Q5 | Old Supply Chain Window | **Keep both** for now (dashboard diagram may stay unused in 2D map flow). |
| Q6 | Resource icons on curves | **Defer** — no midpoint resource icons in P0/P1 (see note below). |
| Q7 | Reduced motion | **Defer** — ship moving dots; add accessibility later if needed. |
| Q8 | Chain-complete celebration | **Yes** — FeedbackBus one-shot; ack stored in `run_stats` so it doesn’t repeat every open. |
| Q9 | Delivery / Equipment Repair | **Pink** shared-support edges; out of normal path loops. Show only when Delivery/Repair itself is selected. |
| Q10 | Multi-instance product links | **Nearest pairing** per catalog connection (not full cross-product). Same-template peers never link. |
| Q11 | Selection / neighbor colors | Selected lot + ring = **dark orange**; previous/next path lots = **light orange**. |
| Q12 | Lot hover tooltip | Panel box (overworld-style opacity): light-orange prev `+$profit` → dark-orange selected → light-orange next `+$profit`. |

### Notes on Q6 / Q7 (plain language)

**Q6 — Resource icons:** Spec optional: tiny Grain / Feed / Eggs icons floating at the middle of each curve. Nice for reading “what flows,” but cluttered and needs art. **Decision: skip for now**; only show that info in the route tooltip text (e.g. `Resource: Grain`).

**Q7 — Reduced motion:** Some players get motion-sick from looping dots. Spec said: if “reduce motion” is on, use a static arrow instead. **Decision: skip for now**; always use the traveling dot. We can add an option later.

## Acceptance notes (from spec)

- Viz overlays the map; does not replace building art.
- Ownership logic stays centralized; renderer only consumes visual state.
- Only active path (or necessary shared edges) is drawn.
- No permanent clutter when mode is off.
- Match farm pixel-art language: chunky, warm, clear contrast.
