# 8.4 — Player feedback juice (animations, indicators, sound)

**Purpose:** Checklist of satisfying feedback for player interactions — small animations, indicators, and sounds that reward action and clarify outcomes.

**Scope:** Capital Farm Godot UI. Prefer a shared feedback bus so Buy Now, Close Deal, chat, and AP spends speak the same language.

**Related:**
- Architecture → [`8.0_godot_migration.md`](8.0_godot_migration.md)
- Community chat → [`8.3_community_social_mechanic.md`](8.3_community_social_mechanic.md)
- Certificate modal → `godot/ui/screens/acquisition_certificate_modal.gd`

**Priority legend:**
- **P0** — highest reward feel per effort (ship first)
- **P1** — game identity / signature moments
- **P2** — depth and polish

**Status values:** `[ ]` todo · `[~]` in progress · `[x]` done · `[-]` cut / deferred


---

## Acceptance notes

- Juice must never block input longer than the animation (except intentional reward holds like certificate settle).
- Deny feedback must be instant and consistent everywhere.
- Celebrations scale with rarity: Buy/Close > notebook unlock > button click.
- Prefer reusing one motion/SFX vocabulary over one-off effects per screen.
- All new SFX/assets live under `godot/assets/` (or agreed audio folder) and are mute-safe.
