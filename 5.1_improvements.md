# EconGame 5.1 — Improvements Checklist

Planning document for Capital Farm / MVP (5) engagement and polish.  
Use this to verify each item is implemented **as intended** before moving on to new features.

**Design principle (north star):**  
Every turn should answer: *“What’s my best move right now, and why?”*

---

## Already implemented (verify behavior in Capital Farm)

These were built in the 5.0 → 5.1 pass. Confirm in-game before treating as done.

### Infrastructure as real estate (Repair Shed + Cold Storage)

- [ ] **Equipment & Repair Shed** and **Delivery & Cold Storage** are offered as **property** deals (price, down %, rent/qtr, vacancy risk) — not standard business acquisitions
- [ ] Both assets live in `portfolio.realEstate`, not `portfolio.businesses`
- [ ] **Quarterly growth (RE rules):** value appreciates ~5–10% per quarter; rent rises ~3% per quarter via `revalueAssets()`
- [ ] **Improve actions** on these assets raise valuation and rent (farm-themed RE improvements in Capital Farm mode)
- [ ] Valuation does **not** auto-appreciate from passive time alone on normal businesses — only via Improve (other 8 farm businesses)

### Supply chain still works for infrastructure

- [ ] Owning Repair Shed or Cold Storage counts toward **owned template IDs** for opportunity bias and strategy classification
- [ ] **Synergies** compute correctly when infrastructure is in `realEstate` (supplier/customer links still fire)
- [ ] **Farm shocks** can hit infrastructure assets (rent/opex adjusted, not business revenue/cost fields)
- [ ] **Portfolio UI** shows infrastructure properties with inputs/outputs, “Property” badge, and active chain tags
- [ ] **Opportunity cards** for infrastructure show chain hint, I/O tags, and “grows like property” note
- [ ] **End-of-run strategy** (`classifyStrategy`) considers infrastructure owned as real estate
- [ ] **Farm network summary** (center panel) appears when player owns businesses *or* farm infrastructure property

### Other eight farm businesses (normal business rules)

- [ ] Grain Farm, Vegetable Farm, Dairy Barn, Poultry Coop, Feed Mill, Bakery, Farmhouse Restaurant, General Store — offered as **business** acquisitions only
- [ ] Growth via **Improve** actions and level-ups; no passive quarterly valuation appreciation
- [ ] Supply-chain synergies, shocks, and missing-dependency hints work as before

## Phase A — Feedback (high ROI, keep core mechanics)

Make outcomes visible so players *feel* progress and consequences each turn.

### Turn debrief

- [x] **Turn debrief card** at end of each turn: net cash flow, net worth delta, debt service, one-line summary
- [x] Debrief highlights **what changed** (e.g. “Rent up 3% on 2 properties”, “1 synergy active”)

### Synergy and chain moments

- [x] **Synergy unlock moment** when a new purchase completes a link (e.g. “Chain live: Repair Shed → Grain Farm (−$800/qtr”)
- [x] Callout when an **existing** synergy becomes strained (capacity on Repair / Cold Storage)

### Improve and portfolio clarity

- [x] **Before/after on Improve** (business and property): show valuation, rent/revenue delta immediately in log or UI
- [x] **Portfolio story line**: one sentence under portfolio — e.g. “You’re 1 asset from closing the protein loop”
- [x] Use `strategicHint` / missing dependencies to drive that line

### Milestones and wins

- [x] **Milestone fanfare** on net worth tier-ups (visual or copy — not just a log entry)
- [x] **Deal close debrief** after negotiation: final price, financing used, vs. asking

## Phase B — Balancing (pacing and fairness)

Keep runs engaging without making them trivial.

### Opportunity pacing

- [x] **Stronger bias** toward missing critical supply-chain links once player owns 2+ assets (extend current `templateWeights`)
- [x] **Guaranteed chain-hint deal** every N turns if a critical dependency is still missing
- [x] **Deal expiration tension** surfaced clearly (“expires this turn”) so FOMO is readable, not hidden

### Early run

- [x] **Starter hook:** first Capital Farm run offers one discounted infrastructure or obvious synergy pair early (optional tuning)
- [x] **Early cash flow** — first ~5 turns should not feel like pure waiting; enough AP/opportunities to make one meaningful move
- [x] **Softer first shocks** — farm events before player has ~2 assets are dampened or skipped

### Action economy (AP)

- [x] Player can infer **priority** among Investigate / Negotiate / Improve / Urgent without guessing
- [x] Optional: subtle UI hint when urgent problem stake > value of current best opportunity

### Negotiation variety

- [x] **Stakes ladder:** small deals feel quick; large deals feel weightier (copy, rounds, or swing size)
- [x] Outcomes feel different by archetype and intel — not same template every time

## Phase C — Light mechanics (extend core loop)

Only add systems that reuse negotiate / buy / improve / chain.

### Recurring characters

- [x] **Named recurring NPCs** visible in UI (lender, client, supplier memory across turns)
- [x] Next encounter reflects prior deal (terms, trust, or one-line callback)

### Rhythm and antagonist

- [x] **Seasonal quarter** (optional): e.g. harvest bonus on grain/veg, winter cost on perishables — gives turn rhythm
- [x] **Rival farmer:** every 3 turns, contests best acquisition opp — 3-way turn-based negotiation vs Cassius Rowe
- [x] **Reputation meter** unlocks better financing or negotiation intel; tied to urgent problem outcomes

### Run variety

- [x] **One wildcard event per run** (auction, inheritance, fire sale) — breaks pattern without permanent complexity
- [x] Wildcard uses existing acquisition/negotiation flow

### End-of-run report

- [x] Richer debrief: best deal, worst shock, dominant chain, strategy label + one-line summary
- [x] Encourages “one more run” without new core systems

### NPC and negotiation

- [x] Negotiation prompts include farm-capitalism tone without drowning out numbers

## Out of scope for 5.1 (keep main mechanics)

Do **not** add for this pass unless explicitly reprioritized:

- Combat, action minigames, or second economy
- Replacing turn-based AP core with real-time systems
- Full simulator / Capital Farm parity changes (simulator keeps legacy templates)
- Multiplayer or leaderboard (solo MVP)
